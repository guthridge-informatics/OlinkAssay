`{OlinkAssay}` is intended to supply methods for importing, processing, correcting, and generally using data from Olink HT assays. Additionally, a S4 container class derived from [`SummarizedExperiment`](https://bioconductor.org/packages/release/bioc/html/SummarizedExperiment.html) is provided that facilitates working with Olink data and allows its use with the wider variety of Bioconductor packages

## Warning!

This package is still under active development and may, at the moment, be in a completely broken state. Probably shouldn't use for the moment unless you are willing to dive into code and fix stuff.

Essentially, there's a good chance that right now that this thing is broken and will eat your data.

## Installation

You can install the development version of olinkqc from [GitHub](https://github.com/) with:

``` r
# install.packages("pak")
pak::pak("guthridge-informatics/olinkqc")
```
