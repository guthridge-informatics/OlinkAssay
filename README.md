`{OlinkAssay}` is intended to supply methods for importing, processing, correcting, and generally using data from Olink HT assays. Additionally, this package provides a S4 container class derived from `{SummarizedExperiment}::SummarizedExperiment` that facilitates working with Olink data and allows its use with the wider variety of Bioconductor packages

## Warning!

This package is still under active development and may, at the moment, be in a completely broken state. Probably shouldn't use for the moment until this unless you are willing to fix stuff.

Theres a good chance that right now, this thing is broken. <early>
